## 三大机房实测怎么样？

### 洛杉矶（LAX）

DMIT 的主力机房，套餐最全，库存相对充裕。

Pro 系列走三网 CN2 GIA：电信去程 AS4809，联通去程 AS4837 直连，移动去程香港 CMI，三网回程全走 CN2 GIA。在同价位里，这条线路的晚高峰表现数一数二。实测到国内延迟大约在 150-200ms 左右（物理距离决定的，这个延迟在跨太平洋线路里算优秀）。

EB 系列（Eyeball）：联通和电信 AS9929/AS58807 负载均衡，移动 AS58807，三网回程 CMIN2。价格比 Pro 便宜不少，网络质量也够用，做代理节点或者跑中等流量的业务没问题。

T1 系列是国际线路，走 GSL + Lumen 等 Tier 1 运营商，带宽给得很大（最高 10Gbps），价格也是洛杉矶最低的，年付从 $36.9 起。但如果你主要访客在大陆，T1 的晚高峰体验会明显不如 Pro/EB。

### 香港（HKG）

对大陆用户来说延迟最低的选择。物理距离近，香港 Pro 到国内三网延迟通常控制在 20-50ms，这个数字比洛杉矶好了整整一个档次。

## FAQ 常见问题

**Q：DMIT 的 CN2 GIA 和普通 CN2 有什么区别？**

A：CN2 GIA（Global Internet Access）是中国电信旗下的高端骨干网络，走 AS4809，比普通 CN2（AS4134）优先级更高，丢包率更低，晚高峰稳定性明显更好。DMIT Pro 系列三网回程全走 CN2 GIA，这是它价格偏高的核心原因。

**Q：DMIT 支持支付宝购买吗？**

A：支持。支付宝、微信支付、PayPal、信用卡都可以，国内用户购买没有障碍。

**Q：洛杉矶 Pro 和 EB 系列怎么选？**
